Use this folder for homepage and site-wide visual assets.

## Founder image

Current homepage reference:

- `/media/profile-placeholder.svg`

Recommended replacement workflow:

1. Add the real founder photo here, for example `founder-profile.jpg`
2. Update [data/company.ts](/f:/WORK/ASB%20Market%20Research/data/company.ts)

## Suggested asset guidance

- Use a professional portrait with neutral background
- Recommended minimum width: `1200px`
- Prefer `.jpg` or `.webp`
- Keep lighting natural and framing formal
