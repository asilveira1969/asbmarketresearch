# Content

Use this directory for localized site copy and future editorial collections.

- `pages.ts`: shared copy for core pages and FAQs
- `services.ts`: service collection used by `/services` and `/services/[slug]`
- `insights.ts`: article collection used by `/insights` and `/insights/[slug]`
- `reports.ts`: sample report collection used by `/sample-reports` and `/sample-reports/[slug]`
